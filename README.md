## Stack Technologique

- **Canvas 2D** — Projections matricielles, Z-buckets, TypedArrays, particles systems
- **WebGL / Three.js r128** — BufferGeometry, LineSegments, surface de révolution, additive blending
- **CSS 3D** — preserve-3d, translateZ, mix-blend-mode: screen, gyroscope
- **Post-processing** — EffectComposer, RGBShiftShader
- **JavaScript pur** — Pas de framework, 60 FPS constant
- **ExtendScript** — 9 scripts d'automatisation InDesign
