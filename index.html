Série Poulpe - Visualisations 3D Canvas

La série Poulpe explore différentes techniques de rendu 3D en utilisant Canvas 2D avec projections mathématiques. Chaque variation offre une approche unique pour visualiser une forme complexe en trois dimensions.

Poulpe Original

Canvas 2D SVG Parser Math 3D

Approche : Première implémentation du concept. Utilise le parsing SVG pour extraire le contour de la pieuvre, puis applique une extrusion 3D avec rotation matricielle.

Caractéristiques :

  • ✦ Rotation interactive à la souris
  • ✦ 4 couches de profondeur (Z-buckets)
  • ✦ Dégradé cyan → bleu selon Z
  • ✦ Motion blur avec traînée
  • ✦ Vertices : ~4500 points
Canvas 2D SVG path sampling Rotation matrices Perspective projection

Poulpe Responsive

Canvas 2D Responsive

Amélioration : Version adaptée pour tous les types d'écrans. Le canvas redimensionne automatiquement sa résolution en fonction de la taille d'affichage (vmin). Supporte les inputs tactiles.

Caractéristiques :

  • ✦ Responsive grid (90vmin)
  • ✦ Touch/Mouse dual input
  • ✦ Inertie avec friction
  • ✦ DevicePixelRatio handling
  • ✦ Rotation automatique au repos
CSS Media Queries Touch Events Dynamic DPI

Poulpe Holographique

Canvas 2D Double-Pass Optimisé

Optimisation : Version ultra-performante avec rendu en deux passes. La première crée un effet glow flou, la seconde ajoute les lignes brillantes du cœur.

Caractéristiques :

  • ✦ 2 passes de rendu (glow + core)
  • ✦ LineWidth adaptatif selon Z
  • ✦ TypedArrays (Float32Array)
  • ✦ Gradients linéaires per-edge
  • ✦ Sections : 260, Segments : 4
TypedArray Gradient rendering Batch drawing

Poulpe Matrice Statique

Particles Physics

Approche particules : Approche entièrement différente. Au lieu de dessiner des lignes, la pieuvre est composée de 12 000+ particules distribuées dans l'espace 3D.

Caractéristiques :

  • ✦ 12 000 particules
  • ✦ Ondulations cinétiques (velocity-based)
  • ✦ 8 tentacules analytiques
  • ✦ Bulbe central (2500 points)
  • ✦ Palette néon (cyan + magenta)
Particle System Kinetic Animation Color Interpolation

Poulpe Premium

3D Mesh Geometry Haute qualité

Haute géométrie : Modèle 3D avec maillage circulaire ultra-détaillé. Chaque point du chemin SVG génère un anneau volumétrique avec 12 segments tangentiels.

Caractéristiques :

  • ✦ 950 sections de spine
  • ✦ 12 segments circulaires par anneau
  • ✦ ~11 400 vertices (950 × 12)
  • ✦ Distorsion aquatique sinusoïdale
  • ✦ Breathing effect (respiration)
3D Mesh Generation Parametric Geometry Organic Deformation

Poulpe MAX

Dégradé Dynamique Peak Performance

Version maximale : Combine géométrie dense (950 sections) avec dégradés adaptés à la profondeur. Les couleurs changent fluidement en temps réel selon la valeur Z de chaque segment.

Caractéristiques :

  • ✦ Coleurs dynamiques (lerp H/L/S)
  • ✦ Z-Buckets (4 couches)
  • ✦ 60 FPS stable
  • ✦ Sections : 950, total edges : ~3000
  • ✦ Hue interpolation (180° → 260°)
HSL Color Space Z-depth Buckets Performance Optimized

Pieuvre 3D Filaire (Three.js)

Three.js WebGL LineSegments

Approche WebGL native : Utilise Three.js pour créer une surface de révolution 3D. Le profil 2D du contour est tourné autour de l'axe Y pour générer une forme volumétrique authentique.

Caractéristiques :

  • ✦ Surface de révolution (600 points × 64 slices)
  • ✦ Deux familles de géométrie (méridiens + parallèles)
  • ✦ Lighting avec dégradé HSL
  • ✦ Additive blending
  • ✦ Halo de points 3D en arrière-plan
Three.js r128 WebGL BufferGeometry

Pieuvre Projection Perspective

Maths 3D Projection Pure

Formule magistrale : Implémente la projection perspective fondamentale : x' = X/Z. Chaque point 3D est projeté sur l'écran en divisant ses coordonnées par sa profondeur Z.

Caractéristiques :

  • ✦ Projection affine (x' = X/Z, y' = Y/Z)
  • ✦ Zoom scrollable (0.4 → 3x)
  • ✦ Couleurs basées sur Z (hue 180° → 260°)
  • ✦ Rotation fluide à la souris
  • ✦ Surface d'extrusion paramétrique
Perspective Math Canvas 2D Pure JavaScript

Variations Holographiques - CSS 3D

Les visualisations holographiques utilisent CSS 3D Transform pour créer un effet de profondeur layérisé. Plusieurs copies du même SVG sont superposées avec interpolation de couleur et d'opacité.

Holographie 3D Base

CSS 3D SVG Layering

Concept de base : 20 calques SVG superposés avec profondeur CSS 3D. Chaque calque a une couleur interpolée du bleu royal (#12005e) au cyan néon (#00f3ff).

Caractéristiques :

  • ✦ 20 couches d'extrusion
  • ✦ Parallaxe souris (rotateX/Y)
  • ✦ Glow progressif (drop-shadow)
  • ✦ Screen blending mode
  • ✦ Perspective 1000px
CSS 3D Transform CSS Variables Drop Shadow Filter

Conclusion

Cette collection démontre plusieurs approches complémentaires pour visualiser des formes complexes en 3D web :

  • Canvas 2D : Contrôle bas-niveau, performance maximale, géométrie manuelle
  • WebGL : GPU acceleration, géométries complexes natives
  • CSS 3D : Effet parallaxe, facilité d'intégration, support mobile

Chaque approche offre des avantages distincts. Le choix dépend des contraintes (performance, compatibilité, complexité géométrique) et de l'objectif (démonstration, animation, interaction).
